## Explicitly not sold as land
**Earth** is reference-only. Atlas 259 must not create a competing "Earth land registry" because real property rights already exist and a digital product could be misleading. Earth can be used as the home/launch reference map, traffic origin, mission route visualization, or educational layer.

## Scientific source policy
Named features and coordinates should come from authoritative public sources:
- NASA Planetary Data System and NASA/JPL mission data for imagery/body metadata
- USGS/IAU Gazetteer of Planetary Nomenclature for approved feature names, coordinates, feature types, and coordinate systems

Every imported feature should preserve source, source version/update date, body, approved name, feature type, coordinate system, and latitude/longitude.

## Commercial rule
Official scientific names remain official scientific names. A user's paid label is a board label / sponsorship marker only and must never overwrite or imply ownership of an IAU-approved name.
